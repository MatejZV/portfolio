# Skill icons

These SVGs are served locally; the Skills section makes no requests to an icon CDN.

- `html5.svg`, `css3.svg`, `javascript.svg`, `typescript.svg`, `git.svg`, `csharp.svg`: original-color SVGs from [Devicon v2.16.0](https://github.com/devicons/devicon/tree/v2.16.0/icons), copied without changes from each technology's `*-original.svg`. MIT license: `LICENSE-devicon.txt`.
- `database.svg`: [Tabler Icons v3.21.0 database outline](https://github.com/tabler/tabler-icons/blob/v3.21.0/icons/outline/database.svg). MIT license: `LICENSE-tabler.txt`. The stroke was changed from `currentColor` to navy (`#1e3a5f`) so it renders correctly as an external image. SQL is a language with no single vendor logo; this generic database symbol avoids implying a specific database product.

Brand marks belong to their respective owners. The images use empty alt text because each adjacent visible heading already names the technology. This avoids duplicate screen-reader announcements. Cards are informational articles, with no unnecessary tab stops; the existing Skills navigation link and section focus behavior are preserved.
